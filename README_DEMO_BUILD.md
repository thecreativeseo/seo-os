# SEO OS — Investor Demo Build Pack (P0 + P1)

This pack is designed to be placed directly into the root of your SEO OS repository and used with Claude Code.

## Build order

Use the prompts in this exact order:

1. `prompts/01_PLAN_P0.md`
2. `prompts/02_BUILD_P0.md`
3. Open/test/polish P0
4. `prompts/03_PLAN_P1.md`
5. `prompts/04_BUILD_P1.md`
6. Open/test/polish P1

Do not paste all prompts at once.

## Investor story

```text
P0 — CONTEXT
Who are we serving and what matters?

P1 — EVIDENCE
What is actually happening?

P2 — OPPORTUNITY
Where should we focus?

P3 — DIAGNOSIS
Why is it happening and what should we do?

P4 — EXECUTION
Can we create and execute approved work?
```

For this first demo, build P0 and P1 well. P2–P4 can be shown as the roadmap.
